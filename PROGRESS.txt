BLOCKER (why the build was not run)
  The cloud environment this was written in has a network policy that blocks every host Loom
  needs: maven.fabricmc.net, meta.fabricmc.net, piston-meta.mojang.com, piston-data.mojang.com,
  libraries.minecraft.net, masa.dy.fi (MaLiLib), maven.terraformersmc.com (Mod Menu),
  api.modrinth.com. Without them Loom cannot download Minecraft, the mappings, Fabric Loader,
  Fabric API or MaLiLib, so nothing that references Minecraft could be compiled or launched.
  Reachable: Maven Central, Gradle plugin portal, GitHub.

What WAS verified instead
  * Pure-Java core (src/main/java/dev/redstonelab/core): compiled with javac -Xlint:all
    (0 warnings) and exercised with a scratch test harness: 27/27 checks pass
    (pulse meter incl. 0-tick pulses and inconsistent clocks, run statistics/variance,
    sparkline, Dijkstra path search, test-trace diff incl. sub-tick order differences,
    Gson round-trip of saved tests).
  * FULL STUB COMPILE (all 71 mod sources, main + client): 0 errors, javac -Xlint:all clean
    for mod code. Classpath: real Mixin (net.fabricmc:sponge-mixin 0.17.4), real MixinExtras,
    Netty, Gson, Guava, fastutil, JOML, Brigadier (built from Mojang's source); stubs for
    Fabric Loader/API, MaLiLib 0.27.19 and Mod Menu written from their actual source
    signatures; Minecraft stubs written from the signatures cross-checked below. This proves
    the mod is type-correct Java against those signatures; it cannot prove the Minecraft
    signatures themselves (only Loom with the real game jar can).
  * Every source file was compiled against the libraries that ARE reachable (Gson, fastutil,
    Guava, JOML, slf4j, MixinExtras, annotations). All remaining errors are unresolved
    Minecraft / Fabric / MaLiLib / Mixin types; no errors involve the mod's own classes.
    (This caught and fixed one real bug: payload records shadowing a helper named type().)
  * Every Minecraft / Fabric / MaLiLib API used was checked by name against the 1.21.11
    sources of Fabric API, Carpet, MaLiLib 0.27.19 and Litematica 0.26.14 (all use Mojang
    mappings) wherever those sources use it. See "UNVERIFIED API ASSUMPTIONS" below for the
